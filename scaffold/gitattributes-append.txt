
# Patch files and Windows-only text must keep Unix line endings.
# Drupal's own list does not cover *.patch, .gitignore or *.ps1. On Windows,
# Laragon's Git ships with core.autocrlf=true globally; this repo overrides
# that locally (core.autocrlf=false). Attributes still have to name every
# extension or a core update that rewrites .gitattributes would check them
# out as CRLF again. Composer appends this file on every install.
#
# *.patch: git apply refuses CRLF against LF targets; Composer then looks
# for a `patch` binary that Windows often does not have. See docs/backlog.md,
# 2026-08-13 and 2026-08-31.
*.patch     text eol=lf
.gitignore  text eol=lf
*.ps1       text eol=lf
